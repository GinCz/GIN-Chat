## 🛡️ Бескомпромиссная безопасность и шифрование

GIN-Chat построен по архитектуре нулевого доверия к серверу (**Zero-Knowledge Architecture**):

* 🔐 **Сквозное E2EE-шифрование сообщений и файлов (AES-256-GCM):**
  * Текстовые сообщения, вложения и персональные данные шифруются непосредственно на клиентском устройстве (в браузере или приложении) с использованием криптографических стандартов **Web Crypto API**.
  * Сервер выступает исключительно как слепой ретранслятор зашифрованных блоков и базы данных. Даже при полном доступе к серверу прочитать переписку третьим лицам математически невозможно.
* 📞 **Высший уровень защиты голосовых и видеозвонков (WebRTC DTLS / SRTP):**
  * Все аудио- и видеоразговоры проходят по защищенному P2P-каналу с использованием криптографических протоколов **DTLS 1.3** и **SRTP** (Secure Real-time Transport Protocol).
  * Прямой обмен медиапотоками между устройствами собеседников исключает перехват или прослушивание голоса и видео на промежуточных узлах.
* 🛡️ **Защита метаданных:**
  * Никаких трекеров, сторонней аналитики, интеграций с рекламными сетями или внешними CDN.
  * Персональные контакты (телефон, email) строго изолированы и никогда не передаются другим участникам.

## 🌍 Автономный Выделенный Сервер и Доступность из Любой Точки Мира

Для работы GIN-Chat развертывается **отдельный независимый выделенный сервер (Dedicated Standalone Server)**:

1. 🌐 **Глобальная доступность без блокировок:** 
   * Прямое выделенное подключение по защищенному протоколу HTTPS/WSS без использования посредников и агрессивных прокси-сетей, что гарантирует стабильное и мгновенное открытие чата из **России, Европы, Азии, Америки и любой точки земного шара**.
2. 🚀 **Высочайшая производительность:**
   * Сервер обслуживает соединения через высокоскоростной движок на базе Node.js, SQLite с WAL-журналированием и веб-сервер Nginx с поддержкой HTTP/2 и постоянных WebSocket-соединений.
3. 🔒 **Изолированное хранилище данных:**
   * База данных пользователей, диалогов и хэшей хранится в зашифрованном изолированном томе.

## 📱 Кроссплатформенность и установка как приложение (PWA)

GIN-Chat устанавливается на любое устройство в виде полноценного автономного приложения без необходимости загрузки из Google Play или App Store:

* **🖥️ Windows Desktop (Google Chrome, Cent Browser, Microsoft Edge, Brave):**
  * На экране входа и в меню доступна кнопка **«Установить GIN-Chat на устройство»** (или иконка установки в адресной строке браузера).
  * Приложение открывается в отдельном изолированном окне без рамок браузера, закрепляется в меню «Пуск» и на панели задач.
* **📱 Android (Chrome, Cent, Samsung Internet, Edge):**
  * В один клик добавляется на главный экран смартфона (WebAPK), работает в полноэкранном режиме с нативным интерфейсом.
* **🍏 Apple iOS / iPhone & iPad (Safari):**
  * В Safari нажать **«Поделиться»** ➔ выбрать **«На экран "Домой"»** (Add to Home Screen). Приложение запускается в чистом Standalone-виде.

## 🚀 Развертывание на новом сервере за 1 минуту

Развернуть собственный независимый экземпляр GIN-Chat на любом чистом Linux-сервере (Ubuntu/Debian, x86_64 / ARM64):

### Вариант 1. Через Docker Compose (Рекомендуемый)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/GinCz/GIN-Chat.git /opt/gin-chat
cd /opt/gin-chat

# 2. Запустить контейнер
docker compose up -d

# 3. Проверить статус
docker compose ps
```

### Вариант 2. Прямой запуск через Node.js (systemd)

```bash
cd /opt/gin-chat
npm install --production
PORT=3000 node server.js
```
